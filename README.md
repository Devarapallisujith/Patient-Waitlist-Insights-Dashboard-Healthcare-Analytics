# Patient-Waitlist-Insights-Dashboard-Healthcare-Analytics
## Project Overview
This project focuses on analyzing patient waitlist data in the healthcare sector using an interactive Power BI dashboard.
The dashboard helps understand patient demand, waiting time patterns, and specialty-wise waitlist distribution to support better decision-making.
The analysis highlights key metrics such as latest month waitlist, previous year comparison, case type distribution, age profiles, and monthly trends.
## Project Objectives
- Analyze patient waitlist trends over time.
- Identify the specialties with the highest waiting lists.
- Compare Day Case, Inpatient, and Outpatient demand.
- Understand age group distribution of patients.
- Monitor monthly waitlist trends.
## Key Insights
- Outpatients contribute the largest share of the total waitlist.
- Certain specialties consistently show higher patient demand.
- Waiting time varies significantly across different age groups and time bands.
- The monthly trend analysis helps identify changes in healthcare service demand.
## Dataset Features
The dataset includes the following attributes:
- Archive_Date
- Speciality_Name
- Age_Profile
- Time_Bands
- Case_Type
- Day Case
- Inpatient
- Outpatient
- Total Waitlist
## Tools & Technologies Used
- Power BI
- DAX (Data Analysis Expressions)
- Data Cleaning & Transformation
- Data Modeling
- Interactive Data Visualization
## Dashboard Features
- KPI Cards for waitlist comparison.
- Case type distribution analysis.
- Age profile vs time band analysis.
- Top 5 specialties with highest waitlists.
- Monthly trend analysis.
- Interactive filters for better exploration.
## Project Goal
The goal of this project is to demonstrate data analytics and visualization techniques using healthcare data to identify trends and support decision-making.
## Conclusion
This project demonstrates how Power BI can be used to analyze healthcare patient waitlist data through interactive dashboards. It provides insights into waitlist trends, case type distribution (Day Case, Inpatient, Outpatient), age profiles, and specialty demand. The dashboard helps transform raw healthcare data into clear visual insights that support better decision-making and resource planning.
